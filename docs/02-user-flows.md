# Flujos principales

## Cliente

Landing → registro/login → elegir problema → detalles/fotos/video → diagnóstico preliminar → dirección → horario → precio → pago → matching → técnico confirmado → seguimiento → cierre → review → historial.

## Profesional

Invitación → onboarding → documentación/herramientas/zonas → revisión → aprobación → solicitudes → aceptar/rechazar → estados → registro de equipo → diagnóstico real → cierre → QR → pagos.

## Admin

Dashboard → invitar/aprobar profesionales → configurar precios/diagnóstico → ver solicitudes → asignar → supervisar trabajos → controlar pagos → calidad/reclamos/garantía → auditoría.
